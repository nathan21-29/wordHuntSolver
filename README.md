## Hello!

This is a repo that contains Word Hunt Solver, an algorithm that uses recursive steps to find words within a 2d word grid.
Word Hunt Solver was written as an Eclipse project, and I plan to address issues with the default working directory of the files not being correct.

For the sake of transparency, this code in this repo was written for the ICS4U grade 12 computer science course in the Ontario curriculum in October of 2025.
